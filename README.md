# Резюме и портфолио работ

Статический сайт из одного файла `index.html`. Сборка не нужна.

## Vercel

1. vercel.com/new, импортировать репозиторий или перетащить папку.
2. Framework Preset: Other, Build Command пустой, Output Directory пустой.
3. Deploy.
